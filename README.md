**Vad är versionshantering och vad är den stora skillnaden mellan att spara en fil via editorns vanliga sparaknapp och att spara ändringar i Git?**
*Versionshantering betyder att man kan spara olika versioner av sitt arbete och se vad man har ändrat. När jag trycker på spara i VS Code sparas bara ändringarna i filen. Med Git kan jag spara olika versioner med commits och se mina tidigare ändringar. Om jag gör fel kan jag gå tillbaka till en tidigare version.*

**Beskriv vad kommandona git status, git add och git commit gör i det dagliga arbetsflödet och när du kör dem.**
*git status använder jag för att se vilka filer jag har ändrat och om de är redo att sparas. git add använder jag när jag vill välja vilka filer som ska komma med i nästa commit. git commit använder jag sedan för att spara ändringarna som en version med ett meddelande om vad jag har gjort.*

**Vad är skillnaden mellan mappen på din dator och repot på GitHub, och vad gör kommandot git push?**
*Mappen på min dator är där jag arbetar med mina filer och gör ändringar. Repot på GitHub är en plats på internet där jag kan spara och visa mitt projekt. Med kommandot git push skickar jag mina commits från datorn till GitHub så att ändringarna finns där också.*
